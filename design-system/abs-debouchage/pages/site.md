# Overrides — tout le site ABS Débouchage

- **Typographie** : Lexend (titres, 600/700) + Source Sans 3 (texte, 400/600/700) — pairing « Corporate Trust » (domain typography).
  Le pairing EB Garamond/Lato proposé par défaut vise les cabinets juridiques : écarté pour un service de dépannage.
- **Couleurs** : marine #0B2545 (texte/marque), bleu #1E40AF (liens, accents), orange #C2410C uniquement pour les appels (blanc dessus = 5,2:1), WhatsApp vert avec texte foncé.
- **Formes** : rayon 8–12 px, ombres légères, aucune pastille décorative, aucun emoji, icônes SVG au trait.
- **Mouvement** : apparition 12 px / 350 ms, prefers-reduced-motion respecté. Pas d'effets de défilement décoratifs.
- **Diagnostic express** : 3 étapes avec indicateur « Étape X sur 3 », labels visibles, erreur sous le champ, retour possible.
